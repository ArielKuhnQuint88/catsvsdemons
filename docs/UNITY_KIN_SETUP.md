# Adicionar Kin controlável

## Atualizar

1. No GitHub Desktop, clique em **Fetch origin**.
2. Clique em **Pull origin**.
3. Volte para a Unity e aguarde a compilação.

## Criar Kin

Abra:

```text
Tools → Cats vs Demons → Add Kin Prototype
```

Será criada uma cápsula branca com faixa vermelha e espada dourada em:

```text
Game → Player → Kin_Prototype
```

## Testar

1. Abra a aba **Game**.
2. Pressione o botão **Play**.
3. Movimente Kin usando:
   - `WASD`; ou
   - setas do teclado.
4. Pressione **Play** novamente para parar.

Kin se movimenta em relação à câmera isométrica, vira para a direção do movimento e não pode sair dos limites do tabuleiro.

## Salvar e enviar

1. Pressione `Ctrl + S`.
2. No GitHub Desktop, faça o commit:

```text
feat: add controllable Kin prototype
```

3. Clique em **Push origin**.
