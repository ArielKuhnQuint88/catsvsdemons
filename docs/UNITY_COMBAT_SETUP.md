# Combate e moedas

## Atualizar

1. GitHub Desktop → **Fetch origin**.
2. Clique em **Pull origin**.
3. Aguarde a Unity compilar.

## Adicionar

Abra:

```text
Tools → Cats vs Demons → Add Combat and Coins
```

## Testar

1. Pressione **Play**.
2. Aproxime Kin de um demônio.
3. Vire Kin na direção do inimigo.
4. Ataque com:
   - barra de espaço; ou
   - botão esquerdo do mouse.
5. Cada golpe causa 10 de dano.
6. O demônio possui 30 de vida.
7. Após três golpes, ele morre e concede 5 moedas.

Os valores aparecem no **Console** nesta fase.

## Salvar

Faça o commit:

```text
feat: add Kin combat enemy health and coins
```

Depois clique em **Push origin**.
