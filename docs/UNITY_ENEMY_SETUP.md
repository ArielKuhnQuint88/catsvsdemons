# Adicionar demônio em movimento

## Atualizar

1. GitHub Desktop → **Fetch origin**.
2. Clique em **Pull origin**.
3. Volte para a Unity e aguarde a compilação.

## Criar o protótipo

Abra:

```text
Tools → Cats vs Demons → Add Moving Demon Prototype
```

Será criado um demônio roxo provisório na entrada esquerda.

## Testar

1. Abra a aba **Game**.
2. Pressione **Play**.
3. Observe o demônio:
   - surgir no início do caminho esquerdo;
   - percorrer os pontos em ordem;
   - virar nas curvas;
   - parar próximo da casa.
4. Kin continua controlável com `WASD`.

## Salvar e enviar

Faça o commit:

```text
feat: add moving demon prototype
```

Depois clique em **Push origin**.
