# Moedas e primeira torre

1. No GitHub Desktop, use **Fetch origin** e **Pull origin**.
2. Espere a Unity terminar de compilar.
3. Execute **Tools > Cats vs Demons > Add Coins and First Tower**.
4. Entre no modo Play.
5. Clique em um ponto de construção para gastar 10 moedas e criar uma torre.

O protótipo começa com 20 moedas. Derrotar demônios acrescenta 5 moedas.
