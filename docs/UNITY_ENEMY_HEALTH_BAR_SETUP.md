# Barra de vida dos demônios

## Atualizar

1. GitHub Desktop → **Fetch origin**.
2. Clique em **Pull origin**.
3. Aguarde a Unity compilar.

## Adicionar

Abra:

```text
Tools → Cats vs Demons → Add Enemy Health Bars
```

A barra será adicionada ao modelo utilizado pelo sistema de ondas. Todos os demônios criados durante a partida terão a barra automaticamente.

## Testar

1. Pressione **Play**.
2. Aproxime Kin de um inimigo.
3. Ataque com `Espaço` ou clique esquerdo.
4. A barra perde um terço a cada golpe.
5. No terceiro golpe, o demônio desaparece e concede moedas.

## Salvar

Faça o commit:

```text
feat: add enemy health bars
```

Depois clique em **Push origin**.
